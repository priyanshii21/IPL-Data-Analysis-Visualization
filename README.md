
# IPL Data Analysis & Visualization

This project analyzes IPL match data using Python, Pandas, and Matplotlib to identify important match, team, player, toss, venue, and season-wise trends.

### Key Analysis

* Highest and lowest winning margins
* Matches won by each team
* Matches played in each season
* Matches held in different cities and stadiums
* Top players based on Man of the Match awards
* Toss wins and toss decisions
* Relationship between winning the toss and winning the match
* D/L method analysis
* Different types of match results
* Best teams and venues for defending totals

### Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook
* IPL Dataset

The project focuses on Exploratory Data Analysis (EDA) and data visualization to understand IPL match patterns and extract meaningful insights from historical match data.
